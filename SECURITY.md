# Security and Confidential Disclosure

Do not file public issues containing vulnerabilities, credentials, customer information, private media, architecture details that would facilitate abuse, or other confidential information.

Report suspected security or confidentiality incidents privately to the repository owner through an approved secure channel. Include the affected surface, reproduction steps, impact, and whether any sensitive data was accessed. Do not access, download, alter, or retain data beyond what is necessary to demonstrate the issue.

Production access is least-privilege and may be revoked at any time. Secrets must never be committed to this repository.
